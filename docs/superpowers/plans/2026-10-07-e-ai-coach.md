# AI Coach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional **Coach** that reviews the user's logs, plans their workouts, estimates a meal's nutrition, and chats about all of it, through OpenAI, Anthropic, Google, xAI, or any OpenAI-compatible server such as Ollama or OmniRoute, falling back to the next account with the conversation intact when one hits a limit, and tracing every request to Langfuse when its keys are set.

**Architecture:** `source/ai.ts` holds the provider-neutral core: accounts merged from `config.json` and the shell's keys, a classifier that turns any failure into a cooldown, and a fallback loop that tries each account in order with the same messages. Providers, the AI SDK, and Langfuse load with `import()` only when a request is made, so a user without AI never pays for them. `source/coach.ts` builds the context from the logs, the instructions, the output schemas, and `coach.json`. `App` receives an `asker` the way it receives an `updater`, so tests drive the Coach with a fake one and never touch the network.

**Tech Stack:** AI SDK 7 (`ai` 7.0.130, `@ai-sdk/openai` 4.0.86, `@ai-sdk/anthropic` 4.0.74, `@ai-sdk/google` 4.0.90, `@ai-sdk/xai` 5.0.17, `@ai-sdk/openai-compatible` 3.0.65), Langfuse JS 5 (`@langfuse/otel`, `@langfuse/tracing`, `@langfuse/vercel-ai-sdk` 5.13.1), `@opentelemetry/sdk-node` 0.223.0, `@opentelemetry/api` 1.9.1, zod 4, Ink 7, AVA 7.

**Spec:** [`2026-10-07-roadmap.md`](./2026-10-07-roadmap.md), section "Call AI Through the AI SDK, Behind a Fallback Chain" and the contracts for Plan E. Depends on [Plan A](./2026-10-07-a-environment-settings.md) (`config.json`, the variable registry, `writeVariable`, the `env` prop) and [Plan C](./2026-10-07-c-daily-logging.md) (the log arrays, `todayOf`, `profileNow`, `targetsOf(profile, goals)`, `streakOf`, `suggestionsOf`, the Log view).

The API shapes below were checked against the installed type definitions of these exact versions on 2026-10-07: AI SDK 7 renamed `system` to `instructions`, `experimental_telemetry` to `telemetry`, and `experimental_output` to `output`, and moved OpenTelemetry out to an integration registered with `registerTelemetry`.

## Global Constraints

- No network without a key: with no account and no Langfuse keys, nothing in this plan imports a provider, the AI SDK, or OpenTelemetry
- Keys live only in `config.json` (mode 600) or the shell; never in `progress.json`, `coach.json`, an event, the footer, or a Langfuse trace's metadata
- An event names the provider or the kind of request, never a key, a prompt, or an answer
- Fallback is for resilience, never for evading limits: there is no round-robin mode, and the README warns that rotating free accounts of 1 provider breaks its terms
- The Coach gives general guidance, not medical advice; the instructions say so and point to a professional for medical questions
- Pin every new dependency to an exact version, as `package.json` already does
- xo enforces `react-hooks/purity` and `react-hooks/immutability`: no `Date.now()` during render, no writes to props inside a component
- Every user-facing string in all 3 languages; `npx prettier --write` changed files, then `npm test`, after every task

## Review Focus

- An account whose provider returns 401 for a revoked key: the Coach falls back to the next account and the failed one stays skipped for the rest of the run, instead of failing every request first
- Every account cooling down at once: the Coach still tries them, soonest-ready first, rather than refusing to ask
- Esc while a request is in flight: the request is aborted, the fallback loop stops, and no answer arrives later to overwrite the screen
- A model that answers a plan request with JSON that does not fit the schema: the Coach says it could not read the plan instead of saving a broken one
- A Langfuse base URL that cannot be reached: answers still arrive, because exporting traces never blocks a request

```tsx
// The slice of a long list to show, keeping the cursor in the middle when it can.
export function windowOf(index: number, count: number, limit?: number) {
	if (limit === undefined || count <= limit) {
		return { start: 0, end: count };
	}

	const start = Math.min(
		Math.max(index - Math.floor(limit / 2), 0),
		count - limit,
	);
	return { start, end: start + limit };
}
```

### Task 2: The Fallback Chain

**Files:**

- Create: `source/ai.ts`
- Modify: `package.json`, `package-lock.json` (the AI SDK and its providers)
- Test: `source/tests/ai.test.ts`

**Interfaces:**

- Consumes: Task 1's `Account`, `Provider`, `Config`, and `Environment`
- Produces:
  - `defaultModels: Record<Provider, string>`
  - `accountsOf(config: Config, env: Environment): Account[]` (saved accounts first, then 1 per provider key in the shell)
  - `type FailureKind = "rateLimited" | "quota" | "auth" | "unavailable" | "badRequest" | "network" | "aborted"`
  - `type Failure = Readonly<{ kind: FailureKind; message: string; retryAfter?: number }>`
  - `failureOf(error: unknown): Failure`, `cooldownOf(failure: Failure): number` (milliseconds)
  - `type Attempt = Readonly<{ account: Account; failure?: Failure }>`
  - `type Fallback<Result> = Readonly<{ ok: true; result: Result; account: Account; attempts: readonly Attempt[] }> | Readonly<{ ok: false; attempts: readonly Attempt[] }>`
  - `withFallback<Result>(accounts: readonly Account[], call: (account: Account) => Promise<Result>, options?: { cooldowns?: Map<string, number>; now?: () => number; signal?: AbortSignal; onAttempt?: (account: Account) => void }): Promise<Fallback<Result>>`

`ai.ts` never imports a provider or the AI SDK at the top: errors are recognized by their shape, and providers load inside the call in Task 4, so loading the dashboard stays as fast as today.

| Failure       | When                                                         | Cooldown                                  |
| ------------- | ------------------------------------------------------------ | ----------------------------------------- |
| `aborted`     | The user pressed Esc                                         | None, and the loop stops                  |
| `auth`        | 401 or 403                                                   | 24 hours, so the run never tries it again |
| `badRequest`  | 400, 404, or 422, such as a retired model                    | 1 hour                                    |
| `network`     | No HTTP status: offline, DNS, refused, or timed out          | 30 seconds                                |
| `quota`       | 402, or a 429 whose body mentions quota, credits, or billing | 1 hour                                    |
| `rateLimited` | Any other 429                                                | `retry-after`, or 60 seconds              |
| `unavailable` | 408, 409, 5xx, or Anthropic's 529                            | 30 seconds                                |

```ts
// source/tests/ai.test.ts
import test from "ava";
import { APICallError, RetryError } from "ai";
import {
	accountsOf,
	cooldownOf,
	defaultModels,
	failureOf,
	withFallback,
} from "../ai.js";
import type { Account } from "../config.js";

const account = (
	id: string,
	provider: Account["provider"] = "openai",
): Account => ({
	id,
	provider,
	label: id,
	apiKey: `key-${id}`,
	model: defaultModels[provider],
});

const callError = (statusCode: number, body = "{}", headers = {}) =>
	new APICallError({
		message: `HTTP ${statusCode}`,
		url: "https://api.example.com",
		requestBodyValues: {},
		statusCode,
		responseHeaders: headers,
		responseBody: body,
	});

test("turns every failure into a kind and a cooldown", (t) => {
	t.like(failureOf(callError(429, "{}", { "retry-after": "12" })), {
		kind: "rateLimited",
		retryAfter: 12_000,
	});
	t.is(
		cooldownOf(failureOf(callError(429, "{}", { "retry-after": "12" }))),
		12_000,
	);
	t.is(cooldownOf(failureOf(callError(429))), 60_000);
	t.is(
		failureOf(callError(429, '{"error":{"code":"insufficient_quota"}}')).kind,
		"quota",
	);
	t.is(
		failureOf(callError(429, "RESOURCE_EXHAUSTED: quota exceeded")).kind,
		"quota",
	);
	t.is(failureOf(callError(402)).kind, "quota");
	t.is(failureOf(callError(401)).kind, "auth");
	t.is(cooldownOf(failureOf(callError(401))), 24 * 3_600_000);
	t.is(failureOf(callError(404)).kind, "badRequest");
	t.is(failureOf(callError(529)).kind, "unavailable");
	t.is(failureOf(callError(503)).kind, "unavailable");
	t.is(failureOf(new TypeError("fetch failed")).kind, "network");
	t.is(failureOf(new DOMException("aborted", "AbortError")).kind, "aborted");
	t.is(
		failureOf(
			new RetryError({
				message: "gave up",
				reason: "maxRetriesExceeded",
				errors: [callError(401)],
			}),
		).kind,
		"auth",
		"a retry error is judged by its last error",
	);
});

test("falls back to the next account with the same request", async (t) => {
	const seen: string[] = [];
	const cooldowns = new Map<string, number>();
	const result = await withFallback(
		[account("first"), account("second", "anthropic")],
		async (next) => {
			seen.push(next.id);

			if (next.id === "first") {
				throw callError(429, "{}", { "retry-after": "30" });
			}

			return "answer";
		},
		{ cooldowns, now: () => 1000 },
	);

	t.like(result, { ok: true, result: "answer", account: { id: "second" } });
	t.deepEqual(seen, ["first", "second"]);
	t.is(cooldowns.get("first"), 31_000);
	t.false(cooldowns.has("second"));
});

test("skips accounts that are cooling down, but tries them when all are", async (t) => {
	const seen: string[] = [];
	const call = async (next: Account) => {
		seen.push(next.id);
		return next.id;
	};

	const cooldowns = new Map([["first", 5000]]);
	t.like(
		await withFallback([account("first"), account("second")], call, {
			cooldowns,
			now: () => 1000,
		}),
		{
			account: { id: "second" },
		},
	);

	seen.length = 0;
	const all = new Map([
		["first", 9000],
		["second", 5000],
	]);
	await withFallback([account("first"), account("second")], call, {
		cooldowns: all,
		now: () => 1000,
	});
	t.deepEqual(seen, ["second"], "the soonest ready goes first");
});

test("reports every attempt when all fail, and stops on Esc", async (t) => {
	const failed = await withFallback(
		[account("first"), account("second")],
		async () => {
			throw callError(503);
		},
		{ cooldowns: new Map(), now: () => 0 },
	);

	t.false(failed.ok);
	t.deepEqual(
		failed.attempts.map((attempt) => [
			attempt.account.id,
			attempt.failure?.kind,
		]),
		[
			["first", "unavailable"],
			["second", "unavailable"],
		],
	);

	const controller = new AbortController();
	const seen: string[] = [];
	const stopped = await withFallback(
		[account("first"), account("second")],
		async (next) => {
			seen.push(next.id);
			controller.abort();
			throw new DOMException("aborted", "AbortError");
		},
		{ cooldowns: new Map(), now: () => 0, signal: controller.signal },
	);

	t.false(stopped.ok);
	t.deepEqual(seen, ["first"]);
});

test("adds the shell's keys after the saved accounts", (t) => {
	const saved = account("mine", "google");
	const accounts = accountsOf(
		{ env: {}, accounts: [saved] },
		{ ANTHROPIC_API_KEY: "sk-ant-1", OPENAI_API_KEY: "sk-1" },
	);

	t.deepEqual(
		accounts.map((next) => [next.id, next.provider]),
		[
			["mine", "google"],
			["env:openai", "openai"],
			["env:anthropic", "anthropic"],
```

```ts
export type FailureKind =
	| "rateLimited"
	| "quota"
	| "auth"
	| "unavailable"
	| "badRequest"
	| "network"
	| "aborted";

export type Failure = Readonly<{
	kind: FailureKind;
	message: string;
	retryAfter?: number;
}>;

type CallError = Readonly<{
	statusCode?: number;
	responseHeaders?: Record<string, string>;
	responseBody?: string;
}>;

// The AI SDK's errors, recognized by shape so this module never loads the SDK.
const isCallError = (error: unknown): error is Error & CallError =>
	error instanceof Error && "statusCode" in error;

const lastErrorOf = (error: unknown): unknown =>
	error instanceof Error && "lastError" in error ? error.lastError : error;

// ponytail: reads only `retry-after` in seconds; parse the providers' own reset
// headers if a 60-second guess proves too coarse.
const retryAfterOf = (headers: Record<string, string> | undefined) => {
	const seconds = Number(headers?.["retry-after"]);
	return Number.isFinite(seconds) && seconds > 0 ? seconds * 1000 : undefined;
};

export function failureOf(thrown: unknown): Failure {
	const error = lastErrorOf(thrown);
	const message = error instanceof Error ? error.message : String(error);

	if (error instanceof Error && error.name === "AbortError") {
		return { kind: "aborted", message };
	}

	if (!isCallError(error) || error.statusCode === undefined) {
		return { kind: "network", message };
	}

	const status = error.statusCode;
	const body = (error.responseBody ?? "").toLowerCase();

	if (
		status === 402 ||
		(status === 429 && /quota|credit|billing/v.test(body))
	) {
		return { kind: "quota", message };
	}

	if (status === 429) {
		return {
			kind: "rateLimited",
			message,
			retryAfter: retryAfterOf(error.responseHeaders),
		};
	}

	if (status === 401 || status === 403) {
		return { kind: "auth", message };
	}

	if (status === 408 || status === 409 || status >= 500) {
		return { kind: "unavailable", message };
	}

	return { kind: "badRequest", message };
}

const second = 1000;
const hour = 3_600_000;

export function cooldownOf(failure: Failure): number {
	switch (failure.kind) {
		case "rateLimited": {
			return failure.retryAfter ?? 60 * second;
		}

		case "quota":
		case "badRequest": {
			return hour;
		}

		case "auth": {
			return 24 * hour;
		}

		case "unavailable":
		case "network": {
			return 30 * second;
		}

		case "aborted": {
			return 0;
		}
	}
}

export type Attempt = Readonly<{ account: Account; failure?: Failure }>;

export type Fallback<Result> =
	| Readonly<{
			ok: true;
			result: Result;
			account: Account;
			attempts: readonly Attempt[];
	  }>
	| Readonly<{ ok: false; attempts: readonly Attempt[] }>;

// Cooldowns last for this run only; a restart tries every account again.
const runCooldowns = new Map<string, number>();

// Tries each account in order with the same call until 1 answers. Accounts
// cooling down wait their turn, unless every account is, and Esc stops it all.
export async function withFallback<Result>(
	accounts: readonly Account[],
	call: (account: Account) => Promise<Result>,
	{
		cooldowns = runCooldowns,
		now = Date.now,
		signal,
		onAttempt,
	}: Readonly<{
		cooldowns?: Map<string, number>;
		now?: () => number;
		signal?: AbortSignal;
		onAttempt?: (account: Account) => void;
	}> = {},
): Promise<Fallback<Result>> {
	const readyAt = (account: Account) => cooldowns.get(account.id) ?? 0;
	const ready = accounts.filter((account) => readyAt(account) <= now());
	const order =
		ready.length > 0
			? ready
			: accounts.toSorted((left, right) => readyAt(left) - readyAt(right));
	const attempts: Attempt[] = [];

	for (const account of order) {
		if (signal?.aborted) {
			break;
		}

		onAttempt?.(account);

		try {
			// eslint-disable-next-line no-await-in-loop -- 1 account at a time, in order.
			const result = await call(account);
			cooldowns.delete(account.id);
			return {
				ok: true,
				result,
				account,
				attempts: [...attempts, { account }],
			};
		} catch (error) {
			const failure = failureOf(error);
			attempts.push({ account, failure });

			if (failure.kind === "aborted") {
				break;
			}

			cooldowns.set(account.id, now() + cooldownOf(failure));
		}
	}

	return { ok: false, attempts };
}
```

```ts
// source/tracing.ts
import type { Environment } from "./config.js";

export type TraceAttributes = Readonly<{
	sessionId: string;
	tags: readonly string[];
}>;

export type Tracer = Readonly<{
	isOn: boolean;
	trace: <Result>(
		name: string,
		attributes: TraceAttributes,
		work: () => Promise<Result>,
	) => Promise<Result>;
}>;

const untraced: Tracer = {
	isOn: false,
	trace: async (_name, _attributes, work) => work(),
};

let started:
	| Promise<Readonly<{ tracer: Tracer; stop: () => Promise<void> }>>
	| undefined;

async function start(env: Environment) {
	const [
		{ NodeSDK },
		{ LangfuseSpanProcessor },
		{ LangfuseVercelAiSdkIntegration },
		{ propagateAttributes, startActiveObservation },
		{ registerTelemetry },
	] = await Promise.all([
		import("@opentelemetry/sdk-node"),
		import("@langfuse/otel"),
		import("@langfuse/vercel-ai-sdk"),
		import("@langfuse/tracing"),
		import("ai"),
	]);
	const processor = new LangfuseSpanProcessor({
		publicKey: env.LANGFUSE_PUBLIC_KEY,
		secretKey: env.LANGFUSE_SECRET_KEY,
		baseUrl: env.LANGFUSE_BASE_URL ?? "https://cloud.langfuse.com",
		environment: "terminal-sigma",
	});
	const sdk = new NodeSDK({ spanProcessors: [processor] });
	sdk.start();
	registerTelemetry(new LangfuseVercelAiSdkIntegration());

	const tracer: Tracer = {
		isOn: true,
		trace: async (name, attributes, work) =>
			startActiveObservation(name, async () =>
				propagateAttributes(
					{
						traceName: name,
						sessionId: attributes.sessionId,
						tags: [...attributes.tags],
					},
					work,
				),
			),
	};

	return {
		tracer,
		async stop() {
			await processor.forceFlush();
			await sdk.shutdown();
		},
	};
}

// Langfuse starts once, and only when both keys are set; otherwise nothing
// is loaded and nothing is sent.
export async function tracerOf(env: Environment): Promise<Tracer> {
	if (!env.LANGFUSE_PUBLIC_KEY || !env.LANGFUSE_SECRET_KEY) {
		return untraced;
	}

	started ??= start(env);
	return (await started).tracer;
}

// Sends what is still buffered before the process exits.
export async function stopTracing() {
	if (started) {
		await (await started).stop();
	}
}
```

```ts
export type Turn = Readonly<{ role: "user" | "assistant"; content: string }>;

export type AskRequest = Readonly<{
	accounts: readonly Account[];
	kind: string;
	instructions: string;
	turns: readonly Turn[];
	sessionId: string;
	schema?: zod.ZodType;
	env: Environment;
	signal?: AbortSignal;
	onAttempt?: (account: Account) => void;
}>;

export type AskReply = Fallback<unknown>;
export type Asker = (request: AskRequest) => Promise<AskReply>;

// 1 request, traced as 1 trace, tried on each account until 1 answers.
export const aiAsker: Asker = async (request) => {
	const [{ generateText, Output }, tracer] = await Promise.all([
		import("ai"),
		tracerOf(request.env),
	]);
	const functionId = `coach-${request.kind}`;

	return tracer.trace(
		functionId,
		{ sessionId: request.sessionId, tags: [request.kind] },
		async () =>
			withFallback(
				request.accounts,
				async (account) => {
					const common = {
						model: await modelOf(account),
						instructions: request.instructions,
						messages: request.turns.map((turn) => ({ ...turn })),
						maxRetries: 0,
						timeout: 60_000,
						abortSignal: request.signal,
						telemetry: { functionId },
					};

					if (request.schema) {
						const result = await generateText({
							...common,
							output: Output.object({ schema: request.schema }),
						});
						return result.output as unknown;
					}

					return (await generateText(common)).text;
				},
				{ signal: request.signal, onAttempt: request.onAttempt },
			),
	);
};
```

```ts
export function withTurns(
	coach: Coach,
	session: Session,
	turns: Session["turns"],

	return {

						? { ...known, turns: [...known.turns, ...turns] }
						: known,

	};
```

```ts
// The order the fallback tries, with 1 account moved up or down a place.
export function movedAccounts(
	accounts: readonly Account[],
	id: string,
	step: -1 | 1,
): Account[] {
	const from = accounts.findIndex((account) => account.id === id);
	const to = from + step;
	const next = [...accounts];

	if (from < 0 || to < 0 || to >= accounts.length) {
		return next;
	}

	const [moving] = next.splice(from, 1);

	if (moving) {
		next.splice(to, 0, moving);
	}

	return next;
}
```

```tsx
import { spinnerFrames, usePalette } from "../theme.js";
import Choice, { type Option } from "./choice.js";

export type CoachMode = "menu" | "ask" | "read";

type CoachViewProps = Readonly<{
	messages: Messages;
	mode: CoachMode;
	options: readonly Option[];
	session?: Session;
	// The account being asked right now.
	asking?: string;
	// The option the cursor returns to after a request.
	initialOption?: string;
	isSetUp: boolean;
	height: number;
	onSelect: (value: string) => void;
	onAsk: (text: string) => void;
}>;

// The requests, a spinner naming the account being asked, and the latest
// answer; Read shows the whole session from a turn the arrows choose.
export default function CoachView({
	messages,
	mode,
	options,
	session,
	asking,
	initialOption,
	isSetUp,
	height,
	onSelect,
	onAsk,
}: CoachViewProps) {
	const palette = usePalette();
	const { coach } = messages;
	const turns = session?.turns ?? [];
	const [offset, setOffset] = React.useState(Math.max(turns.length - 1, 0));
	const { frame } = useAnimation({
		interval: 120,
		isActive: asking !== undefined,
	});

	useInput(
		(_input, key) => {
			if (key.upArrow) {
				setOffset((current) => Math.max(current - 1, 0));
			} else if (key.downArrow) {
				setOffset((current) =>
					Math.min(current + 1, Math.max(turns.length - 1, 0)),
				);
			}
		},
		{ isActive: mode === "read" },
	);

	const latest = turns.findLast((turn) => turn.role === "assistant");
	let shown = latest ? [latest] : [];

	if (mode === "read") {
		shown = turns.slice(offset);
	}

	let controls: React.ReactNode = null;

	if (asking) {
		controls = (
			<Text color={palette.accent}>
				{`${spinnerFrames[frame % spinnerFrames.length] ?? "·"} ${coach.asking(asking)}`}
			</Text>
		);
	} else if (mode === "ask") {
		controls = (
			<Box>
				<Text color={palette.accent}>❯ </Text>
				<TextInput
					placeholder={coach.placeholder}
					onSubmit={(text) => {
						if (text.trim()) {
							onAsk(text.trim());
						}
					}}
				/>
			</Box>
		);
	} else if (mode === "menu") {
		controls = (
			<Choice
				initialValue={initialOption}
				options={options}
				onSelect={onSelect}
			/>
		);
	}

	return (
		<Box flexDirection="column" height={height} overflow="hidden">
			<Text bold color={palette.accent}>
				{messages.menu.coach}
			</Text>
			{isSetUp ? null : <Text dimColor>{coach.setUp}</Text>}
			<Box marginTop={1}>{controls}</Box>
			{shown.map((turn, index) => (
				<Box
					// Turns never reorder, and 2 can share a timestamp.
					// eslint-disable-next-line react/no-array-index-key
					key={`${turn.at}-${index}`}
					flexDirection="column"
					marginTop={1}
				>
					<Text
						bold
						color={turn.role === "user" ? palette.soft : palette.accent}
					>
						{turn.role === "user"
							? coach.you
							: (turn.via ?? messages.menu.coach)}
					</Text>
					<Text>{turn.content}</Text>
				</Box>
			))}
		</Box>
	);
}
```

```ts
// The line with an estimate for 1 serving of a food it named, written as
// totals for every serving, so Enter logs it as typed amounts.
export function withEstimate(
	line: string,
	draft: MealDraft,
	estimate: Readonly<{
		calories: number;
		protein: number;
		carbs: number;
		fat: number;
	}>,
): string {
	const text = line.normalize("NFKC");
	const at = text.lastIndexOf(draft.food);
	const total = (value: number) => plain(value * draft.servings);

	if (at < 0) {
		return line;
	}

	return [
		text.slice(0, at),
		`${draft.food} ${Math.round(estimate.calories * draft.servings)}kcal ${total(estimate.protein)}p ${total(estimate.carbs)}c ${total(estimate.fat)}f`,
		text.slice(at + draft.food.length),
	].join("");
}
```

```tsx
		kind: "estimate",
		env,
		schema: estimateSchema,
		sessionId: "estimate",
		signal: aborter.signal,
		instructions: instructionsOf(
			language,
			contextOf(latest.current, Date.now()),
		),
		turns: [
			{ role: "user", content: promptOf("estimate", language, draft.food) },
		],
		onAttempt(account) {
			setAsking(account.label);
		},
	}).then((reply) => {
		if (aborter.signal.aborted) {
			return;
		}

		setAsking(undefined);
		const words = messagesOf(latest.current.language ?? "en");
		const estimate = reply.ok
			? estimateSchema.safeParse(reply.result)
			: undefined;

		if (!reply.ok || !estimate?.success) {
			say(words.log.estimateFailed, "error");
			return;
		}

		setDraftLine((current) => ({
			line: withEstimate(line, draft, estimate.data),
			count: (current?.count ?? 0) + 1,
		}));
		say(words.log.estimated(reply.account.label), "success");
	});
};
```

```markdown
# Calling AI

The Coach is optional, and a user who never sets it up must never pay for it. [`ai.ts`](../../source/ai.ts) tries the user's accounts in order through `withFallback`, [`coach.ts`](../../source/coach.ts) decides what a model sees, and [`tracing.ts`](../../source/tracing.ts) reports to Langfuse only when both of its keys are set.

## Rules That Must Never Break

Each of these protects the user's keys, data, or start-up time:

- **Ask Only Through `withFallback`**: A new request goes through the same loop, so a limit or an outage moves on to the next account with the same messages
- **Keep Fallback for Resilience**: Never add round-robin or load spreading across accounts of 1 provider; OpenAI's terms forbid circumventing rate limits, and others forbid bypassing protective measures
- **Keep Keys Out of Everything but `config.json`**: Not in `progress.json`, `coach.json`, an event, the footer, a prompt, or a trace's metadata
- **Keep Notes Out of the Context**: `contextOf` sends numbers and food names, never the user's notes
- **Load Providers Lazily**: `ai.ts` and `tracing.ts` import the AI SDK, its providers, Langfuse, and OpenTelemetry only with `import()` inside a request
- **Test with a Fake Asker**: Dashboard tests pass `App` an `asker`; no test may reach a real provider

## Updating Models and Packages

`defaultModels` in `ai.ts` names 1 starting model per provider, checked against each provider's model list; check them again whenever the AI SDK is upgraded. The AI SDK 7 options are `instructions`, `messages`, `output: Output.object({ schema })`, `telemetry`, and `maxRetries: 0`, and the Langfuse integration is registered once with `registerTelemetry`.
```
